# Treino35 — Aplicativo de hipertrofia + futebol

Aplicativo React + Vite pronto para publicar gratuitamente na Vercel.

## Publicação sem terminal
1. Extraia o arquivo ZIP no computador.
2. Crie um repositório no GitHub e envie **todos os arquivos e pastas extraídos**, não apenas o ZIP.
3. Entre em https://vercel.com/new, conecte o GitHub e selecione o repositório.
4. Framework Preset: **Vite**. Build Command: `npm run build`. Output Directory: `dist`.
5. Clique em Deploy.

## Rodar localmente
`npm install` e depois `npm run dev`.

## Recursos
- Semana 1 ajustada para o treino de bíceps e tríceps já realizado em 26/10/2026.
- Rotina padrão das semanas 2–8 com futebol segunda e quinta.
- Exercícios, séries, repetições e cardio.
- Registro de cargas, marcação de conclusão, cronômetro e anotações.
- Dados armazenados no navegador com localStorage (sem conta e sem sincronização).

Observação: os treinos são sugestões e devem ser adaptados conforme recuperação e orientação profissional. Quinta-feira com futebol: ajuste intensidade e horário da musculação.
